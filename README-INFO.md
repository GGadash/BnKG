# B&KG: start here

**BnKG is an independent sound level meter desktop app by Gadash (Akila DJ), for compatible HBK 2255 and B&K 2245 instruments through Web-XI/Open Interface.** It provides live readings, instrument-screen viewing, frequency analysis, local capture/review/export, media tools and an offline Demo Lab.

**Under development:** information may be incomplete, delayed or incorrect. Double-check readings, units, timing and settings on the instrument. This software is not manufacturer-endorsed, a calibration tool or proof of measurement/regulatory compliance. Windows binaries are unsigned; platform and hardware limitations are described in the release notes.

## Projects and support

Use [BnKG on GitHub](https://github.com/GGadash/BnKG) to get source, report issues and contribute improvements. More developed or different versions may be available on the [developer page](https://github.com/GGadash/), including [HBKG](https://github.com/GGadash/HBKG). Explore and contribute to those projects too; their features and support differ.

Optional support: [developer Ko-fi](https://ko-fi.com/gadash) · [B&KG / HBKG product](https://ko-fi.com/s/06caf1c2f0).

This software uses FFmpeg playback libraries under LGPL-2.1-or-later. Corresponding source archives are supplied alongside binaries on the [release page](https://github.com/GGadash/BnKG/releases). Optional external FFmpeg encoder executables are downloaded separately; see [setup](docs/FFMPEG_SETUP.md).

# Which release

Choose Standalone, executable Portable or Python Portable. Executable editions include Python; Python Portable needs a supported installed Python and initial dependency setup.

[Read the maintained guide](https://github.com/GGadash/BnKG/blob/main/Readme-info-which-relese-to-get.txt).

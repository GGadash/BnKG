# Connection and safety

Use the current meter address and enable Web server display on the instrument. Arming and confirmations apply to real controls; calibration/service writes remain blocked.

[Read the maintained guide](https://github.com/GGadash/BnKG/blob/main/CONNECTION_GUIDE.md).

Optional support: [Support the developer](https://ko-fi.com/gadash) · [B&KG / HBKG product](https://ko-fi.com/s/06caf1c2f0).

B&KG is under development; double-check readings and settings. More developed/different versions may be available on [GGadash](https://github.com/GGadash/), including [HBKG](https://github.com/GGadash/HBKG).

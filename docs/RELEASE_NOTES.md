# B&KG 0.4.0a1 — development preview

Under development: some information may be incomplete, delayed or incorrect. Double-check readings, units, timestamps and settings on the SLM. Unsigned Windows builds; no manufacturer endorsement or measurement/regulatory compliance claim.

## Included

Dashboard preferences; clearly labelled current/whole-measurement/verified-interval Frequency views; saved files and history; bounded local charts/exports and HTML reports; Demo Lab; original-frame screen recording; FLAC capture and playback; native AAC/Opus and estimated paired MP4 export using optional external FFmpeg; limited evidence-based 2255 BKC totals and direct A/Z spectra. SLM view fits both dimensions, defaults to 200% nearest-neighbor, and has persistent session arming with protected menu entry. Start/Pause after Stop handles the tested ResultMeasured state.

Documentation, credits, package chooser, Wiki sources and both Ko-fi links are refreshed. Public location drafts start empty. Private measurements, handoffs and development history are excluded from the fresh public snapshot.

## Evidence and remaining limits

Historical 2255 firmware 1.3.0.478 controls and read-only acquisition were exercised with explicit authorization. Limited BKC totals matched 174 manufacturer-export values; this does not validate other profiles, native marker uploads or GPS injection. Media encodes/decode passed; playback quality is not certified and synchronization is estimated from PC receipt times.

Release package checks are reported with the GitHub release. Same-PC Windows checks and Linux virtual-display smoke tests are not clean-PC, actual-DPI, real Linux audio or real Linux SLM acceptance. Actual 2245, other firmware and long-run drift still need testing. Critical calibration/reset/service operations remain blocked. No new instrument writes are part of release preparation.

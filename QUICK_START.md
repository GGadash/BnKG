# B&KG quick start

Read [which release to get](Readme-info-which-relese-to-get.txt). Most Windows users should extract Executable Portable and run **Launch-BnKG-Portable.cmd**. Python users can extract Python Portable, run **Setup-BnKG-After-Move.cmd**, then use its portable launcher. Standalone is a single EXE and needs no installed Python.

On first launch, read the usage agreement and explicitly accept to continue, or decline to exit. The app then starts disconnected. Try **Demo Lab** for clearly synthetic examples or connect explicitly to your SLM's current address. See [the user guide](docs/USER_GUIDE.md) and [connection guide](CONNECTION_GUIDE.md). Local capture/logging and physical SLM controls are separate.

This app is under construction. Some information may be incomplete, delayed or incorrect. Double-check it against the physical instrument and official documentation. No regulatory or measurement-validity claim is made. The Windows executables are unsigned development builds.
